# AgentForge · 工程流水线控制台

把「需求 → 规划 → 架构 → 编码 → 自检 → 产物」做成一个可运行的控制台。

**单文件 · 零依赖 · 无后端 · 不消耗任何 API**

---

> https://a-hi1.github.io/agentforge-console/

## 它演示了什么

点「开始运行」，五个阶段依次推进，每一步都有真实日志：

| 阶段 | 做什么 |
|---|---|
| **Planner** | 把任务拆成可交付项 |
| **Architect** | 定接口契约与关键约束 |
| **Coding** | 生成的产物 |
| **Debug** | **质量门禁 + 自动重试** |
| **Deploy** | 打包产物 |

## 两个核心机制（都是真的在算）

### 1. 规则化质量门禁

不是让模型自评「好不好」，而是**从 100 分往下扣**，五条规则：

| 规则 | 扣分 |
|---|---|
| 代码块是否闭合 | -25 |
| 章节是否完整（≥3 节） | -20 |
| 中英文比例（≥25%） | -15 |
| 长度是否充足 | -10 |
| 是否说明边界情况 | -10 |

低于阈值 → **带修复指令重跑**，重跑后分数上升、通过。

> 为什么用规则而不是模型自评：规则可复现、可调参、能向用户解释「为什么扣了这 15 分」。

### 2. 记忆召回

左侧输入的任务描述，会和预置的历史经验做关键词匹配打分，命中的按分数排序显示。

你可以改一句任务描述试试——**召回结果会跟着变**。比如把「订单导出」改成「前端页面」，命中的经验就完全不同。

---

## 试着改这几处

- 改**任务描述** → 记忆召回结果变化
- 拖**质量阈值**到 90 → 第一轮 85 分也算不过，会重试
- 拖到 40 → 一次通过，不触发重试

---

## 实现说明

- 单 HTML 文件，Canvas 之外的 DOM 渲染，无框架
- 流水线用 async/await 串起来，每步可中断
- 门禁是对**产物文本**做正则与统计，不是假的分数
- 全部逻辑在浏览器内跑完，没有任何网络请求
